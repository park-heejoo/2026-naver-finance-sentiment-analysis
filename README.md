# 2026-naver-finance-sentiment-analysis
KoBERT-based Stock Sentiment and Sector Value-Chain Coupling Analysis | KoBERT 기반 종토방 투자심리 분석 및 섹터 밸류체인 주가 동조화 매커니즘 규명 프로젝트

🛠️ 1. 환경 설정 및 실행 방법
본 프로젝트를 로컬 환경에서 복제하고 실행하기 위해 아래의 라이브러리 설치 및 개발 환경 세팅을 진행해 주세요.

📌 필수 라이브러리 설치(Terminal)
콘솔 창을 열고 아래 명령어를 입력하여 데이터 파싱, 전처리, 딥러닝 추론, 시각화에 필요한 마스터 패키지들을 일괄 설치합니다.
Bashpip install requests beautifulsoup4 lxml pandas numpy matplotlib torch transformers tqdm

🗄️ 추천 개발 환경 (Database 시각화)
수집된 대규모 종토방 비정형 시계열 데이터는 SQLite3 로컬 데이터베이스 파일(.db)에 실시간 누적 적재됩니다.
데이터베이스 내부 테이블과 텍스트 적재 현황을 GUI로 간편하게 모니터링하기 위해, VS Code 확장 마켓플레이스에서 SQLite Viewer 프로그램을 설치하여 활용하는 것을 강력히 권장합니다.

📂 2. 프로젝트 아키텍처 및 소스코드 상세 설명
본 프로젝트의 데이터 공급 및 분석 파이프라인은 유기적인 결합성과 코드 재사용성을 극대화하기 위해 [데이터 수집 ➡️ 딥러닝 감정 분석 ➡️ 데이터 통합 ➡️ 시각화 및 검증]의 4단계 모듈러 구조로 설계되었습니다.

🕷️ Phase A. 데이터 수집 인프라 (3-Tier Architecture)
네이버 금융 모바일 주주방 API 트래픽을 안전하게 마스킹하고 데이터를 영속성 있게 관리하는 수집 엔진입니다.
main.py (엔트리 포인트): 데이터 수집 프로세스를 가동하고 제어하는 메인 스크립트입니다. 분석 타깃 종목 코드 및 안전한 분석 경계면인 과거 NID(게시글 고유 ID) 범위를 설정해 가동합니다
.crawler.py (모바일 API 파싱 엔진): 네이버 서버의 데이터 블로킹 및 스크리닝 정책을 우회하기 위해 정밀한 브라우저 헤더 세팅 및 시장 운영 시간별 동적 딜레이(Dynamic Sleep, 1.2초~6.0초 무작위 분산) 알고리즘을 적용한 고안전성 크롤러입니다.
db_manager.py (SQLite3 저장소 매니저): 50개 배치 단위 데이터프레임을 to_sql 문법으로 데이터베이스 파일에 실시간 커밋(Commit)합니다. 저장된 최신 nid를 실시간 역추적하여 데이터 중복 적재를 원천 차단하는 증분 기록 로직을 수행합니다.

🧠 Phase B. 자연어 처리 및 피처 엔지니어링
get_daily_sentiment.py (금융 특화 NLP 감정 분석 엔진): * KoBERT 기반 문맥 추론: 한국어 금융 텍스트 및 뉴스 뉘앙스 분석에 강력한 오픈소스 BERT 임베딩 모델인 DataWizardd/finbert-sentiment-ko 파이프라인을 탑재하여 비정형 게시글의 문맥을 [긍정/중립/부정]으로 정밀 분류합니다.
주주 공감도 가중치($W$) 알고리즘: 단순히 텍스트만 보는 한계를 극복하기 위해, 해당 게시글의 [좋아요(Agree) / 싫어요(Disagree)] 반응 비율을 계산하여 점수를 유기적으로 증폭·감쇄시키는 5단계 가중치 모델을 독자 구현했습니다.
일별 지수 정규화: 호재/악재 발생 시 게시글 수가 급증하는 편차 왜곡을 제거하기 위해, 일별 그룹화 후 정규화하여 0 ~ 100 스케일의 일일 감정 지수(Sentiment Index) 시계열 피처를 빌드합니다.

🤝 Phase C. 데이터 마스터 셋 통합
merge_analysis_data.py (시계열 결합 모듈):
한국거래소(KRX) 인프라를 통해 수집한 일별 종가, 주가 등락률(Change, %) 데이터와 일별 감정 지수를 하나로 융합합니다.
주말 및 공휴일 등 주식 시장 휴장일 동안 쌓인 개미들의 대규모 심리 데이터가 유실되는 것을 막기 위해 Date(날짜) 기준 Outer Join(합집합) 병합을 수행하며, 발생한 주가 공백은 전후방 결측치 보정 기법(ffill, bfill)으로 메워 완벽한 데이터 연속성을 보장합니다.

📊 Phase D. 시각화 및 가설 검증
plot_sector_trends.py (장기 대세 트렌드 - Macro): 일별 등락 노이즈를 흐리게 처리하여 배경에 깔아두고, 그 위에 polyfit을 이용한 1차 직선 추세선(Linear Trendline) 레이어를 굵게 중첩하여 약 4달간의 거시적 주가-심리 뱡향성을 대조합니다.
plot_shock_wave.py (단기 정밀 충격파 - Micro): 5일 이동평균(5-day Rolling Average) 평활화 기법을 적용해 잔파도를 제거한 정갈한 추세선을 그립니다. 상단(주가-실선)과 하단(심리-점선) 이분할 레이아웃과 이벤트 당일 세로 가이드라인을 배치하여 시차 전이(Time Lag)를 현미경처럼 관찰합니다.
